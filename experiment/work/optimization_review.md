# 稀疏短记忆任务：优化与局部卷积机制的独立审查

状态：2026-10-09，新阶段模型训练前的方法审查；最终源码出现后另补实现核查。本文件不修改先前的冻结协议、源码或结果。新阶段来自已经观测到的旧实验现象，属于有新验证集和新测试集的自适应后续研究，不应写成完全未看过旧结果的初始验证。

## 1. 研究问题和能支持的结论

固定阳性概率约 1%、延迟 2 帧、训练池 4096 条独立记录、每条一个评分端点。比较五种模型：原始 GRU、GRU 前接 depthwise conv1 + SiLU、GRU 前接 depthwise conv4 + SiLU、Mamba conv4、Mamba conv1；两种采样优化各 400 次更新、batch 32。

这能检验两个具体机制：对同一个经验风险，更密集地抽到正例是否改善给定训练预算内的学习；以及在保留 SiLU 的对照下，增加局部时间卷积是否改善此短延迟任务。它不直接验证长记忆、连续接触事件、真实触觉或闭环控制，也不能独自归纳成所有 GRU 或 Mamba 的架构定律。

## 2. 经验目标等价的数学条件

设当前训练池有 N 条记录，N+ 个阳性，N- 个阴性，实际比例 pi=N+/N，且两类均非空。令 L+、L- 分别为这两个有限集合上每条记录的普通二元交叉熵均值。

原始方案从整个池中均匀、有放回抽样，使用 `pos_weight=(1-pi)/pi`，按 batch 大小求平均。其随机损失的期望是：

`E[loss_uniform] = pi × ((1-pi)/pi) × L+ + (1-pi) × L- = (1-pi)(L+ + L-)`。

分层方案每批从阳性池及阴性池各均匀、有放回抽取 16 条，使用无类别权重的 BCE，再乘 `2(1-pi)`。其期望是：

`E[loss_balanced] = 2(1-pi) × (0.5 L+ + 0.5 L-) = (1-pi)(L+ + L-)`。

因此两方案的有限训练池目标及裁剪前梯度估计的期望相同。必要条件是使用每个训练 seed 的实际 pi，而不是名义 0.01；每条记录评分数相同且只有一个端点；分类池内均匀抽样；uniform 方案不能每批重新估计类别权重。损失若按加权样本权重和而非 batch 大小归一化，上式不再成立。

梯度裁剪、Adam 的动量/平方梯度和非线性参数更新不保留上述等价性，所以不能声称两种算法有相同的每步更新或训练轨迹。它们的差别正是本实验要考察的优化干预。模型分布外或测试时的概率校准也不能由加权目标直接推断。

## 3. 数据与随机性控制

- 全部五模型和两采样方案共享每个 seed 的完整训练池、验证集和测试集。训练生成 seed 为 510000 至 510009，调参训练生成 seed 510901；验证 520001、8192 条；测试 530001、65536 条。新数据不能与旧测试记录混用或据测试结果选模型。
- 所有方案固定 400×32=12800 次记录呈现，但不具有相同的正例呈现次数或不同正例个数。分层方案精确呈现 6400 次正例，uniform 期望约 128 次；前者对有限约 40 个正例有大量重复。这是有效的优化干预，但不能称为相同“正例预算”。
- 记录完整训练池阳性数、每批阳性数、空阳性批次比例、正例总呈现数、不同正例访问数、不同阴性访问数。呈现总数不等于获取了更多独立样本。
- 同一模型、相同 seed 在两采样方案之间应具有完全相同的初始状态；同一方案跨模型应共享批次索引。对 conv1/conv4 的共同参数要显式复制或核对哈希：仅重设相同 RNG seed 再构造模型，不能保证后续层初始化相同，因为卷积大小改变随机数消耗。
- 卷积核大小改变也会改变其默认初始化方差或参数化。应记录具体规则。即使其他公共参数完全相同，conv4 对比 conv1 仍是这一具体局部卷积参数化的干预，不能把差值纯粹解释成任何架构中的“时间记忆容量”。
- 同为 SiLU 的 GRU conv4 与 conv1 是主要局部性对照；原始 GRU 与 conv1 的差值同时包含额外仿射映射、非线性及参数，不能单独归因于局部时间信息。

## 4. 推断与主对比

三个预先指定的主 AP 差值分别是：

1. C1 = GRU balanced − GRU uniform。
2. C2 = GRU conv4 uniform − GRU conv1 uniform。
3. C3 = Mamba conv4 uniform − Mamba conv1 uniform。

每项报告配对训练 seed 与配对独立测试记录的 bootstrap 区间，置信度 `1−0.05/3=98.333…%`。保持同一次重采样中跨所有模型/采样方案的 seed 权重与测试记录权重一致。主实质差值门槛为 AP 0.03：区间下界超过 0.03 才支持相应方向的有实际大小的改进。整个新阶段内三项校正不覆盖此前阶段或其他探索性结果。

十个训练 seed 同时改变训练数据和初始化，因此 seed 重采样描述这两种来源的组合变异。共同的大测试集仍有有限样本误差，应保留测试记录重采样；不能把十个模型各自的 65536 个预测当作互相独立的训练重复。区间以已经选定的学习率/检查点为条件，不覆盖重新运行验证选择的变异。

98.333% 区间每侧尾部仅 0.833%。1000 次 bootstrap 每侧约 8 个尾部样本，Monte Carlo 波动可能明显。建议至少 5000 次，并保存抽样差值、随机 seed 和区间；若使用更多重采样，应按计算精度决定而非按是否跨越显著性阈值决定。

附加报告跨 seed 的全部散点、失败/成功分布及中位数，避免均值掩盖双峰。仅十个 seed 的百分位 bootstrap 仍是近似推断，不应称作严格分布无关的置信保证。

## 5. “恢复学习”与线索依赖

C1 大于零只说明相对提高，不保证任务已经学会。训练前应明确高性能判据，例如 balanced GRU 平均 AP 的辅助 95% 区间下界高于 0.90；同时检查查询条件下的 AP 和全部 seed 分布。该辅助判据的最终值应在新阶段冻结协议中记录，不能见结果后选门槛。

线索打乱仅交换被标记位置的符号位，并保持其他输入、查询门及原始标签不变。若模型实际使用该线索，预测性能应显著下降。但打乱后查询门仍然在：全体 AP 的参照是 query-only 基线（约 0.5），不是原始阳性比例（约 0.01）；query-conditioned AP 的随机排序参照也约 0.5。应报告精确数据基线、原始与打乱 AP、查询条件 AP，以及它们的配对差值。不能把打乱后 AP 仍约 0.5 解释成保留了一半的记忆能力。

次要差距缩减为 `(Mamba−GRU)_uniform − (Mamba−GRU)_balanced`。它可以支持优化条件影响相对排名，但不等于两模型等效。只有预先定义的等效区间完整位于 ±0.03 内才支持相应 AP 尺度的等效表述；“差异不显著”不能替代等效检验。报告 90%（对应常用双单侧 5% 检验）及 95% 辅助区间，并明确其探索性地位。

## 7. 最终实现审查补记

2026-10-09，新训练开始前已阅读 `optimization_locality.py` 与新协议。发现并报告 CPU 目标等价检查中的 dtype 问题：`torch.where` 的两个 Python 浮点标量生成 float32，无法满足 float64 的 1e-14 容差；主代理随后改用 `full_like/ones_like`。这不是训练损失公式错误。修复后 CPU 前检全部通过，封存时间为 UTC 12:30:37.161253（北京时间 20:30:37）。

实现核查结果：uniform 和 balanced 均仅提取一个评分端点；实际 pi 来源为当前训练池；每批 balanced 正负 16/16；共同的 GRU 主体、卷积偏置及 Mamba 公共形状参数显式配对；conv1 与 conv4 都保留相同位置的 SiLU，并通过左侧 padding 加前缀截取保持因果；训练/验证/测试种子及规模符合协议。未发现需要阻止训练的主要因果、标签或选择错误。

主代理采用了家族内共享学习率：先完成全部 20 次调参，按 GRU 或 Mamba 家族内平均 best validation AP 选一个学习率，之后执行 100 次最终训练。它防止主采样/卷积对比因分别选择学习率而混淆；跨家族的次要差距仍基于各自选定的家族学习率。

独立分析 `analyze_optimization_locality.py` 不导入训练执行函数。它重建所有测试标签、查询、端点和线索位置，重新计算四个 AP 指标；重放全部训练批次并核对索引摘要、访问摘要、每批阳性数、不同正负样本访问数；检查每个模型在两个采样方案间的初始权重摘要一致；核对验证检查点和家族学习率选择。主要 AP 计算器已通过 300 次与实际记录重采样及 sklearn 的逐值对照，包括分数并列和零权重，最大误差 2.22e-16。

仍需区分：线索打乱使用同一固定循环移位，不是在所有可能的置换上平均；消融的辅助区间以该干预为条件。不同记录间的移位供体存在关联，因此消融区间不应被解释为严格的独立随机置换总体保证。三个主对比只使用未打乱的独立测试记录，不受此供体关联影响。
