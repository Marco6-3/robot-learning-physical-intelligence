# v1 独立结果判读

依据 `work/results/synthetic_analysis/analysis.json` 及全部 160 次正式运行日志。三个预设“强支持”判据均未通过。可以保留“固定训练预算下，稀疏、短延迟、小数据条件的 GRU 平均表现更好”这一有限结论，不能写成已强力证明原假设。

## 预设检验

D 为 GRU AP 减 Mamba AP。以下主检验采用 5 个训练重复和 512 条共享测试记录的配对 bootstrap，1000 次重采样；各区间置信水平 98.333%，用于三个主对比的 Bonferroni 校正。只有 5 个训练重复，尾部覆盖率仍是近似估计。

| 命题 | 点估计 | 98.333% 区间 | 判读 |
|---|---:|---:|---|
| H1：1%、100 ms、64 条训练记录的 D | +0.049714 | [+0.006446, +0.121572] | 区间支持正方向，但下界未超过预设 +0.03，未达强支持标准 |
| H2：稀疏条件下，长减短记忆的 D，平均两个数据预算 | −0.012878 | [−0.055126, +0.023369] | 跨零，且未可靠达到 −0.03，证据不足 |
| H3：稀疏度×记忆×数据量的三重差分 | −0.048217 | [−0.132083, +0.030496] | 跨零，证据不足 |

H1 的查询机会内 AP 差为 +0.034409，描述性 95% 区间 [+0.008362, +0.071553]。因此正方向不完全来自识别当前查询门，但也不足以可靠断言具有至少 3 个百分点的优势。不能把这一辅助区间当成额外校正过的确认性结果。

## 关键均值与反向证据

| 事件占比 / 延迟 / 训练记录 | MLP AP | TCN AP | GRU AP | Mamba AP |
|---|---:|---:|---:|---:|
| 1% / 100 ms / 64 | 0.472759 | 0.991715 | 0.997714 | 0.947999 |
| 1% / 100 ms / 256 | 0.467563 | 0.999993 | 0.999047 | 0.999957 |
| 1% / 3.2 s / 64 | 0.510959 | 0.452339 | 0.499651 | 0.485610 |
| 1% / 3.2 s / 256 | 0.530228 | 0.503387 | 0.518269 | 0.509263 |

- H1 条件的种子间标准差：GRU 0.002466，Mamba 0.057264。GRU 在 4/5 个配对种子更好；Mamba 的一个种子 AP=1，高于对应 GRU。它是均值与稳定性的有限证据，不是每次训练都更好的保证。
- 训练记录增至 256 后，GRU 与 Mamba 都接近 1；Mamba 均值略高，差约 0.00091，实际幅度很小。因此不能泛化为 GRU 在短记忆任务上普遍更强。
- TCN 在小数据短记忆条件也达到 0.991715，与 GRU 相差约 0.006；结果并未证明 GRU 是唯一有效或明显优于所有局部时序模型的架构。
- 20% 较密、100 ms 条件下，GRU、TCN、Mamba 的 AP 均约为 1；这些天花板结果限制了架构差异与交互的可识别性。

## 机制诊断

当前查询门本身可带来很高的 AP，不能把全时间 AP≈0.5 当作学会了历史：

| 条件 | `score=query` 的确定性 AP | 查询子集常数分数 AP |
|---|---:|---:|
| 1%、100 ms | 0.468750 | 0.468750 |
| 1%、3.2 s | 0.509375 | 0.509375 |
| 20%、100 ms | 0.503492 | 0.503492 |
| 20%、3.2 s | 0.502657 | 0.502657 |

短记忆、小数据、稀疏条件，GRU 查询 AP 为 0.997724，打乱关键符号后降至 0.483623；Mamba 从 0.963315 降至 0.491234。这与两者确实使用过去信息相符。MLP AP 接近查询门基线，构成合理的局部无记忆对照。

长记忆、稀疏条件的查询 AP 如下：

| 模型 / 训练记录 | 原始查询 AP | 打乱关键符号后 |
|---|---:|---:|
| GRU / 64 | 0.502332 | 0.505981 |
| Mamba / 64 | 0.507143 | 0.503475 |
| GRU / 256 | 0.518269 | 0.521514 |
| Mamba / 256 | 0.509462 | 0.517375 |

它们接近 0.509375 的无记忆参考值，且打乱关键历史没有稳定降低表现。最稳妥的解释是：该训练预算下，两架构都未展示可靠的 64 步延迟读取能力。GRU 与 Mamba 的差距缩小不能解释成 Mamba 学会了长期记忆。

## 可写入报告的结论与范围

> 在参数量匹配、相同数据与 400 次更新预算的人工延迟读取任务中，1% 稀疏、100 ms 延迟、64 条训练记录时，GRU 的平均 AP 和训练稳定性优于本次 Mamba 实现；但置信区间不足以确认预设的至少 3 个百分点优势。训练数据增加后，两者都接近满分。对于 3.2 s 延迟，两者都未表现出可靠历史利用，H2 与 H3 未获支持。

参数量实际为 GRU 19,169、Mamba 19,449、MLP 19,443、TCN 19,111，匹配程度良好。AP 的重算误差最大为 4.44e−16；测试标签在各模型、种子与训练预算间的一致性检查通过。

上述优势不能直接称为与训练预算无关的“内在样本效率”。稀疏短记忆条件中，GRU 和 Mamba 各有 4/5 个重复在最终 400 步选中最佳验证 checkpoint。部分 Mamba 的验证 AP 仍在上升，例如 seed1 从 300 步的 0.931306 升至 400 步的 0.936936；另一些训练损失已近零而验证表现趋于平台，不能统一归因于未充分训练。当前固定矩阵无需为寻找正结果追加实验；若日后要升级为收敛后样本效率的结论，需要另立等预算、明确登记的训练预算敏感性研究。

v1 是算法性延迟队列任务：64 步条件需要保存多个独立符号，时间距离与信息容量一起变化。它不是物理接触模拟，也不是未来事件预测，更不构成真实接触控制优势的证据。单状态记忆 v2 的机制补充须单独报告，并披露其冻结前已查看部分 v1 结果的时间顺序。
