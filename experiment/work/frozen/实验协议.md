# 稀疏事件与时序模型：实验协议 v1

2026-10-09；在查看任何正式模型测试排名之前冻结。用户提供的原设计为 H1–H3、GRU 与 Mamba 对照、稀疏度 × 有效记忆 × 训练量实验。本文件给出本次可执行化选择和证据边界。

## 假设与停止规则

H1：稀疏、短记忆、小数据条件下，GRU 优于 Mamba。H2：增加记忆跨度后，Mamba 相对 GRU 改善。H3：架构差异受稀疏度、记忆跨度和训练量的三因素交互影响。

固定实验矩阵完成后报告支持、反对或证据不足，不以发现显著正结果作为继续尝试或终止的依据。保留所有模型、种子和超参数结果。该轮不许用测试集选超参、阈值、生成器或数据划分。

## 1. 可控机制诊断

采用因果延迟读取任务：输入包含每步独立的 ±1 符号 k、独立可见查询门 q 和 6 个高斯干扰通道；标签 y[t] = q[t] AND (k[t−lag] > 0)。这是算法机制诊断，**不是物理接触仿真**。

- 每条记录 128 步，仅计分第 64–127 步，所有条件输入长度相同。
- 查询门率 2% / 40%，对应标签阳性帧占比期望 1% / 20%。同一底层随机数确保配对。
- lag = 2 / 64；用 20 Hz 作时间尺度示意，对应 0.1 / 3.2 s；这不是实际传感采样证据。
- 训练记录 64 / 256，嵌套子集；验证 256 条、测试 512 条，完整记录独立划分。
- 配对训练数据及初始化种子 0–4；验证、测试和调参数据另用独立固定种子。
- MLP、感受野 31 的局部 TCN、GRU、Mamba-1。局部 TCN 是机制对照，不代表全部 TCN 家族的最优能力。
- 每次 400 次更新、batch 16、完整 128 步反传；AdamW；学习率 0.001 / 0.003，独立调参种子 901；每模型每条件相同搜索次数。每 100 步按验证 AP 保存最佳 checkpoint。
- 类别加权只根据训练标签估计；所有架构共享同一批次索引和输入。
- 验证集最大逐帧 F1 决定阈值，测试阈值固定。主指标为 sklearn average precision（AP，非梯形 PR-AUC），附逐帧 F1。
- 必须同时报告查询门内 AP、打乱历史符号后的 AP、query-only 基线与 oracle；不能把学会查询门当成学会长期记忆。

长延迟要求保留多个独立符号，因此这里同时改变记忆跨度和所需记忆容量。此设计能检验有限预算下的延迟读取能力，不能单独证明真实接触动力学中的低维潜状态记忆规律。

### 主要统计量

定义 D(s,m,n)=AP_GRU−AP_Mamba。

1. H1：D(1%,2,64) > 0.03。两个训练规模只提供两点学习曲线，不夸称完整样本复杂度规律。
2. H2：在 n=64、256 上平均 [D(1%,64,n)−D(1%,2,n)] < −0.03。
3. H3：稀疏/密集之间的记忆效应差，再在小/大训练量之间作差。双侧检验是否非零。

使用配对训练种子和完整测试记录计算不确定性；主检验三项采用 Bonferroni 98.333% 区间。完整报告效应值，不能把区间不含零但小于实际意义阈值称为强支持。

## 2. 真实触觉外部验证

优先审计 FlexiTac 的独立标签。当前公开特征表未见独立滑移事件标签，因此不能用输入阈值作为滑移真值。

改用官方 uSkin 2021 数据集作为独立的真实传感器检测证据：[数据仓库](https://github.com/ARQ-CRISP/slip_detection_dataset_2021)。预期 90 次抓取、3 类物体、180 Hz、54 个触觉通道；下载后以真实文件审计为准。只用人工 tactile_slips_label，1/5 为滑移，其余有效标签为非滑移；不使用输入派生的 tactile_changes_label。

先按完整 trial 划分，再生成因果序列。真实数据阶段配置在训练前另存冻结文件，明确事件率、时间单位、对象泛化和训练量。不能用真实输入窗口长度代替“必要记忆跨度”，也不能把自然数据验证当成可控三因素实验。

主任务是当前时刻**滑移检测**。输入不含未来数据。若执行提前预测，必须用单独协议和正提前量；本轮不将检测指标写成提前预测效果。没有真机实验，不能报告恢复成功率或闭环获益。

## 3. 实现与审计

Mamba 保留官方 Mamba-1 的输入依赖 Δ/B/C、A/D、因果深度卷积、SiLU 门、初始化及优化属性。官方代码固定提交，保存许可和 SHA-256。训练前对照官方顺序参考递推验证扫描前向值和梯度，并测试因果性。

本机为 Windows / RTX 5060 Laptop 8GB，采用纯 PyTorch 非融合扫描。实际显存和耗时可记录，但不能把与 cuDNN GRU 的延迟差解释为优化后架构速度优劣。

每个模型记录实际参数数、完整训练曲线、预测、checkpoint、阈值及数据源哈希。所有中文报告采用 UTF-8 写入并回读核验。
