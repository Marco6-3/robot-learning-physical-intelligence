# 记忆训练路径实验：独立完成核查与解读

## 本次最有力、可以限定范围陈述的结论

在新生成的、只有一个相关位的 lag64 任务上，**GRU 和 Mamba-1 都出现了真正利用早先 cue 内容的成功模型**。因此，此前有限预算下的长任务基线附近表现，不能被解释成“这两种架构在当前参数规模下根本不具备 64 步记忆容量”。这是本次补充最清楚的机制性结果。

GRU 在两条训练路径的五个正式种子上全部达到预先固定的成功判据；Mamba-1 的直接路径 2/5、课程路径 4/5 达标。Mamba 的课程路径点估计提高，但预先固定的两项主比较规则下，其区间仍跨零，**不能将课程训练提升概括为已强力确证的总体效应**，更不能把 4/5 写成 5/5 稳定成功。

## 数据与实现完整性

- 8 次调参、20 次正式训练，28/28 完整；未追加种子或按结果改变预算。每次 2,400 次更新，训练 batch=32，模型/AdamW 实例在六阶段间不重置。
- 全部 28 次训练的优化器步数计数器为 2,400，24 个 lag64 验证点完整。两条路径在同一模型内共享学习率 0.003；模型、路径间每个配对种子的记录/阳性/query 暴露次数一致。
- 每次 76,800 次记录暴露；种子 0–4 的真实阳性暴露次数分别为 14,869、16,181、15,356、16,322、15,402。
- 测试为新的 16,384 条独立记录，其中 6,561 条 query=1、3,352 条阳性；query 条件常数分数基线约 0.510898。
- 同一组测试记录在全部模型、路径和种子之间一致。独立精确重算与已存指标的最大绝对差为 2.22e−16。
- 冻结训练源码、models、common、协议的 SHA 与原登记一致。分析仅接受主控授权的一处浮点合法性勘误：合法范围从 `[0,1]` 放宽至 `[-1e−12,1+1e−12]`；未裁剪任何指标或修改训练、选择、对比及重采样。原源码和旧/新哈希均保留。

## 正式测试结果

以下均为按 lag64 验证全记录 AUPRC 选出的最佳检查点；五种子均值。成功判据为 query AUPRC>0.90 且 cue-shuffle 后下降>0.30。

| 模型 | 路径 | 测试 query AUPRC | 五种子 SD | cue-shuffled query AUPRC | 平均下降 | 成功种子 |
|---|---|---:|---:|---:|---:|---:|
| GRU | 直接 | 1.000000 | 约 0 | 0.506696 | 0.493304 | 5/5 |
| GRU | 课程 | 1.000000 | 约 0 | 0.508181 | 0.491819 | 5/5 |
| Mamba-1 | 直接 | 0.707609 | 0.267043 | 0.512214 | 0.195395 | 2/5 |
| Mamba-1 | 课程 | 0.900425 | 0.222657 | 0.504965 | 0.395459 | 4/5 |

Mamba 直接路径成功的是种子 2、3；失败种子 0、1、4 的 query AUPRC 分别为 0.504639、0.507197、0.526212，且打乱 cue 的下降近零。课程路径成功的是种子 1、2、3、4；种子 0 仍失败，query AUPRC 0.502124，打乱下降约 0.000113。不能删掉这些失败运行或只报告成功曲线。

Mamba 课程均值略高于 0.90，不代表各次运行都越过阈值；其明显的种子方差是本实验的重要结果。

## 两项预先细化的主比较

固定 5,000 次、配对的训练种子与测试记录 bootstrap；两个模型的 query AUPRC 课程−直接效应分别使用 97.5% 区间，Bonferroni 名义家族覆盖率 95%。

| 模型 | 课程−直接 query AUPRC | 97.5% 区间 | 预定正效应是否确证 |
|---|---:|---:|---|
| GRU | 0.000000 | [0.000000, 0.000000] | 否，两个路径均到达当前测试排序天花板 |
| Mamba-1 | +0.192816 | [−0.003799, +0.400260] | 否，区间跨零 |

GRU 的 `[0,0]` 是当前测试记录、成功种子及排序指标饱和下的经验 bootstrap 退化结果，不是架构、训练路径或其他分布之间“普遍完全相等”的证明。

架构对比属于描述性结果。直接路径 GRU−Mamba 的 query AUPRC 为 +0.292391，描述性 95% 区间 [0.095273,0.491998]；课程路径差为 +0.099575，区间 [0,0.299493]。不能把它们改标为本研究另外两项预先注册的主检验。

## 可用于最终结论的措辞

> 在这个参数量匹配、相关容量固定为一位的新固定 2,400 步训练协议中，两种架构都能表现出对 64 步前相关内容的有效检索；单次或短预算的长任务失败不构成内在记忆容量不足的证据。GRU 在当前五个配对种子上更稳定，Mamba 对训练过程更敏感。课程路径的 Mamba 点估计改善与成功次数增加具有机制启发性，但五种子校正区间尚不足以确认其总体改善。

新旧协议同时更改了训练预算、随机数据和验证设置；本实验没有用完全相同训练记录和初始化、只改变更新次数的跨协议对照。因此，不能把新旧结果的变化因果归因于“预算增加”这一单独因素。

这一结论不证明触觉闭环控制收益，也不证明稀疏接触场景中任何模型普遍占优。课程看到短跨度输入变体，direct 与课程的固定 lag64 更新数不等，因此这里研究的是训练路径，并非完全相同固定任务暴露下的公平架构上限比较。
