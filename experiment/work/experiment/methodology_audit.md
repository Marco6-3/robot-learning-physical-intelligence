# 独立方法核查

## Mamba 实现

- `PortableMamba1` 对照官方 `state-spaces/mamba` 提交 `e9594ce1c732d97440f0332fdc43170a2294dbfa`；原始源码、许可证及 SHA-256 已存档。
- 本实验使用实数、逐时间步输入相关的 Δ、B、C。Δ 使用 softplus；Δ 初始偏置对应 0.001–0.1 的对数均匀采样；A 为 `-exp(A_log)`，初始状态谱为 −1 至 −8。
- 因果深度卷积、SiLU 激活、独立 z 分支的 SiLU 门控、D 跳连以及输入/输出投影与官方 Mamba-1 公式一致。外部使用两层残差 pre-LayerNorm。
- 扫描遵循 `h[t] = exp(Δ[t]A) h[t-1] + Δ[t]B[t]u[t]`，与官方离散化相同。可微倍增扫描只用乘法和加法，不用可能下溢的累积乘积除法。
- 长度 17/64 的独立顺序扫描及官方 `selective_scan_ref` 已核验前向和全部输入/参数梯度。此核验覆盖当前实验的实数变 B/C 分支，不宣称覆盖官方 API 的复数、分组状态或增量缓存接口。
- 当前训练使用 float32，不使用 AMP。便携实现的扫描为 O(L log L) 运算；官方融合扫描实现不同，因此当前延迟和显存不能支持 Mamba 架构本身低效的结论。

## 训练与选择

- 核查时，`synthetic.py` 在每次构造模型前设置随机种子，随后 `train` 重置采样随机流，配对模型使用相同训练记录及抽样规则。
- 独立调参训练种子 901、两档学习率、共同验证集、共同更新次数，测试集不参与学习率、检查点和阈值选择。
- `train` 接收已经构造好的模型；单独调用 `train(seed=...)` 无法追溯控制此前的参数初始化，调用方必须先设置种子。
- 推荐统一调用 `optimizer_parameter_groups(model, 1e-4)`；保留 A/D 不衰减，并对所有模型的偏置/归一化参数使用一致的无衰减规则。
- 必须归档最终 `model.config`、参数量、学习率、最佳验证步数、训练步数及数据划分。不同数据量采用同一更新次数，属于固定优化预算比较；不等于相同 epoch，也不等于同等耗时。
- 当前训练计时包含验证与检查点复制，峰值显存包含驻留训练张量；不能充当纯推理时延或单独网络占用。

## 可控生成器的证据边界

- 此生成器是随机符号的固定延迟检索任务，并非接触动力学仿真。查询/阳性事件稀疏，关键符号流却每步都更新；不能把它直接称为“稀疏接触信息”。
- lag=64 要求在未知未来查询位置上检索 64 步前的随机符号；为持续正确回答，模型需要保持近似 64 bit 的移动历史。这比“记住一次稀疏事件直到稍后查询”更接近延迟线问题。
- 长短条件是固定 2/64 步依赖。名义 20 Hz 下可换算为 0.1/3.2 秒，但该频率只是解释尺度，不赋予数据物理真实性。
- MLP 不含时间记忆；TCN 的感受野为 31，因此不可能从输入本身获得 64 步前符号。这两项主要校验已知记忆结构；其失败不能证明 GRU/Mamba 普遍优越。
- 可见查询标记能排除大多数阴性时间步，故全时间 AUPRC 的“无记忆”水平不等于阳性率。必须同时报告查询条件 AUPRC（随机符号无记忆期望约 0.5）、打乱符号诊断及全部阴性结果。
- 用 AUPRC、种子/记录不确定性与有限预算结果描述证据；某模型未学会可由优化、初始化、有限训练预算或表示限制共同导致，不自动归因于架构能力上界。
- 即使得到某个交叉趋势，也只是该任务与真实数据所覆盖分布内的支持。它不能单独确立触觉闭环控制收益、恢复成功率或普遍模型选型定律。
