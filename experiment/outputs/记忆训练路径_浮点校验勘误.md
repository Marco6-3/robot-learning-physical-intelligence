# 记忆训练路径：浮点合法性校验勘误

训练进行中的独立完整性核查发现，scikit-learn 返回的若干验证 AUPRC 为 `1.0000000000000002` 或 `1.0000000000000004`。这是双精度舍入量级的越界，导致分析脚本原先严格检查 `[0,1]` 时拒绝读取正常训练结果。

主控明确授权将**这一处合法性检查**放宽到 `[-1e-12, 1+1e-12]`。保留原分析源码副本；原始数据和指标值完全不改、不裁剪；模型、训练、学习率和检查点选择、重采样、对比定义、置信水平及原统计登记均不改。原始值依旧参与原定计算，不用勘误重新挑选结果。

配套 JSON 保存更正 UTC 时间、旧/新源码 SHA-256、单行差异、截至更正时的受影响条目和最大越界量。训练尚未完成，因此该条目清单是当时观察到的范围，不声称穷尽之后新增结果。

这项更正修复数值读取约束，不改变统计分析计划。原登记 SHA 仍对应保留的原分析源码；后续实际分析使用勘误中列出的新 SHA。
